How the Pipeline Works

A simple automated path from source code to deployment.

STEP 01

GitHub Push

Developers push updated application code to the GitHub repository.

STEP 02

Webhook Trigger

GitHub sends a webhook event to Jenkins to initiate the pipeline.

STEP 03

Jenkins Pipeline

Jenkins checks out the code and runs the configured build and deployment stages.

STEP 04

AWS EC2

The deployment process updates the application files on the target EC2 instance.
